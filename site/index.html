How it works

  1. Connect the CYD with a USB data cable. On a phone, use an OTG adapter.
  2. Press Flash. Your browser shows a device list; choose the CYD's serial port.
  3. If the flash does not start, hold BOOT while connecting, then try again.
  4. Install Launcher first if you want to switch firmware later without a computer.
